## Coordinate System

### Globe Projection

The globe is rendered as a sphere with:

- Radius: **10.0 units**
- Diameter: **20.0 units**

Axis orientation:

| Axis | Direction |
|--------|-----------|
| +Y | North Pole |
| -Y | South Pole |
| +Z | 180° Meridian |
| -Z | 0° Meridian (Prime Meridian) |
| +X | Western Hemisphere |
| -X | Eastern Hemisphere |

### Flat Projections

Flat map projections use a coordinate space with:

- Earth width: **20.0 units**

Axis orientation:

| Axis | Direction |
|--------|-----------|
| +Y | Up |
| +Z | North |
| +X | West |
